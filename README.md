# Aires del Parque · RSO Arquitectos

App web instalable (PWA) para que los compradores sigan el avance de la obra, su unidad y su plan de pagos, y reciban avisos de novedades.

- Hosting: GitHub Pages
- Datos y notificaciones: Firebase (Firestore + Cloud Messaging)
- Cada comprador accede con su código personal. Este repositorio no contiene datos personales ni precios.

Consultas: info@rsoarquitectos.com
